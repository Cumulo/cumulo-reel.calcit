# 对齐 Calcit 0.13.75 类型边界 / Align Calcit 0.13.75 type boundaries

## 中文

- 升级 Calcit、Respo、cumulo-util、calcit.std、calcit-wss 与 ws-edn 依赖。
- 将 struct 定义元数据、构造和更新迁移到 nominal `StructDef`、constructor 与 `struct-with`。
- 收紧 `reel-reducer` 的 updater、session id、operation id、timestamp 与 `dev?` 类型关系，并同步附着测试。
- 迁移 Date、Option、Set/List 与页面可见性边界，清除当前入口的类型告警。
- 新增 Cirru EDN 静态质量基线，确保 Dynamic、nil、unsafe-coerce 与未解析类型债务只降不升。
- 生态 JS codegen 依赖 Calcit 的递归泛型绑定修复 `calcit-lang/calcit#596`。

## English

- Upgrade Calcit, Respo, cumulo-util, calcit.std, calcit-wss, and ws-edn dependencies.
- Migrate struct metadata, construction, and updates to nominal `StructDef`, constructors, and `struct-with`.
- Tighten the updater, session id, operation id, timestamp, and required `dev?` relationships in `reel-reducer`, including its attached test.
- Migrate Date, Option, Set/List, and page-visibility boundaries to warning-free typed APIs.
- Add a Cirru EDN static-quality baseline so Dynamic, nil, unsafe-coerce, and unresolved type debt cannot regress.
- Ecosystem JS codegen depends on the recursive generic-binding fix tracked by `calcit-lang/calcit#596`.
