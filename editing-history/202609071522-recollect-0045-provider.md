# Recollect 0.0.45 provider alignment / 对齐 Recollect 0.0.45 provider

## 中文

- 将 `cumulo-reel.calcit` 发布版本推进到 `0.0.38`。
- 仅把传递依赖从 Recollect `0.0.44` 对齐到 `0.0.45`，使 Calcium 可以严格解析预算化 diff API。
- 不修改 Snapshot、运行时行为或公共 API。

## English

- Advance `cumulo-reel.calcit` to release `0.0.38`.
- Only align the transitive Recollect dependency from `0.0.44` to `0.0.45`, allowing Calcium to resolve the budgeted diff API under strict dependency rules.
- Do not change the Snapshot, runtime behavior, or public API.
