# Calcit 0.14.11 strict migration / Calcit 0.14.11 严格类型迁移

## 中文

- 将 Calcit 与 `@calcit/procs` 升级到 `0.14.11`，并同步已发布的 Respo、Recollect、WebSocket 与标准库依赖。
- 为浏览器和 Node entry 声明目标后端，补齐客户端、服务端、reel、twig、updater 与 UI 定义的结构化 schema。
- 用 `Op`、`Database`、`Session`、`Router`、`ClientStore` 和 `Message` 封闭网络与状态边界，移除全部 `unsafe-coerce`。
- 将类型覆盖从 42/71 个完整定义提升到 62/73；未完整定义降至 11，动态 schema 槽降至 11，并保持动态方法与 deprecated 调用为 0。
- 以不含密码字段的 `ClientUser` 明确隔离服务端用户记录与浏览器状态，并为 `User` 的必填字符串提供合法默认值。
- 增加严格泛型下的 reel reset 与客户端用户投影测试，并让 Actions 执行 definition-attached tests。

## English

- Upgrade Calcit and `@calcit/procs` to `0.14.11`, together with the released Respo, Recollect, WebSocket, and standard-library dependency chain.
- Declare browser and Node targets and add structured schemas across client, server, reel, twig, updater, and UI definitions.
- Close network and state boundaries with `Op`, `Database`, `Session`, `Router`, `ClientStore`, and `Message`, removing every `unsafe-coerce` occurrence.
- Improve full type coverage from 42/71 definitions to 62/73; reduce partial definitions and dynamic schema slots to 11 each, while keeping dynamic method dispatch and deprecated calls at zero.
- Explicitly separate server-side user records from browser state with a password-free `ClientUser`, and give required `User` strings valid defaults.
- Add strict-generic reel reset and client-user projection tests, and run definition-attached tests in Actions.
