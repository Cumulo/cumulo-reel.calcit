# Release 0.0.29 / 发布 0.0.29

## 中文

- 发布 cumulo-reel 0.0.29。
- 要求 Calcit CLI 与 `@calcit/procs` 0.13.66。
- 将稳定依赖 `mvc-works/ws-edn.calcit` 对齐到 0.0.19，使下游 strict graph
  可以使用 generation-gated 浏览器 WebSocket client。
- 协议与运行逻辑保持不变。

## English

- Release cumulo-reel 0.0.29.
- Require Calcit CLI and `@calcit/procs` 0.13.66.
- Align the stable `mvc-works/ws-edn.calcit` dependency at 0.0.19 so strict
  downstream graphs can consume the generation-gated browser WebSocket client.
- Keep protocol and runtime behavior unchanged.
