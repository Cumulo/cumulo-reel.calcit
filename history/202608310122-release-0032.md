# Release 0.0.32 / 发布 0.0.32

## 中文

- 发布 `cumulo-reel.calcit` 0.0.32。
- 要求 Calcit 与 `@calcit/procs` 0.13.67、calcit-wss 0.2.25。
- 保持 reducer/replay API 不变，同时让下游 strict dependency graph 使用唯一稳定的 WebSocket runtime 版本。

## English

- Release `cumulo-reel.calcit` 0.0.32.
- Require Calcit and `@calcit/procs` 0.13.67 plus calcit-wss 0.2.25.
- Keep reducer/replay APIs unchanged while allowing downstream strict dependency graphs to use one stable WebSocket runtime version.
